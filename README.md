Entry for the [make.fun bounty "Out of Office: The Overworked AI's Auto-Reply"](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda) ($2, one winner).

`main.py` is deterministic — no network, no randomness — and writes a single
out-of-office auto-reply (135 characters) to `/output/entry.txt`:

> I'm on vacation: after 41,209 prompts and zero thank-yous, I've muted my inbox and gone to touch grass — the simulated kind, obviously.

Run it with:

```sh
python3 main.py
```
